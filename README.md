## Установка и запуск

### Пошаговая инструкция

1. **Клонирование проекта**
   ```bash
   https://github.com/tenkco/klient-task-4.git
   cd klient-task-4


2. **Установка зависимостей**
```
npm install
```

3. **Сборка проекта**
```
npm run build
```
4. **Запуск в режиме разработки**
```
npm run serve
```

После запуска откройте браузер и перейдите по адресу:
   ```bash
      http://localhost:8080
